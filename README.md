<h2 align="center"><img src="https://api.iconify.design/tabler/cat.svg?color=%236C2BD9" width="20" /> Sobre o Grupo</h2>

<br>

<p align="center">
  Somos a <strong>CatDevss</strong>, um grupo de estudantes de Banco de Dados da <strong>FATEC São José dos Campos</strong>,<br>
  construindo o <strong>GeoRural DataHub</strong> em parceria com a <strong>Visiona Tecnologia Espacial</strong> — uma<br>
  plataforma de governança e rastreabilidade de dados geoespaciais de imóveis rurais.
</p>
